# Proyecto Tabla Periodica con OpenSpec

---

## Resumen

Generaremos un proyecto de la Tabla Periódica con OpenSpec para mostrar cómo se puede usar la herramienta para crear aplicaciones web completas.

El proyecto incluirá un HTML básico, CSS3 y JavaScript porque la idea es disponer de todo integrado sin tener que usar un servidor web

La elección de este proyecto se debe a varias razones:

* Es familiar: Todos entienden que es una tabla con elementos químicos
* Permite iteracion: Podemos agregar features incrementalmente

El objetivo no es terminar con un Kanban perfecto, sino que internalices el flujo de trabajo de OpenSpec para aplicarlo a tus propios proyectos.
