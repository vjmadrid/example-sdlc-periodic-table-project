## Paso 1: Instalación de OpenSpec

Pasos a seguir:

* Instalar OpenSpec globalmente con npm:

```bash
# Comando
npm install -g @fission-ai/openspec@latest
```

* Verificar la instalación

```bash
# Comando
openspec --version
```

Debe mostrar la versión instalada de OpenSpec, confirmando que está listo para usar.
